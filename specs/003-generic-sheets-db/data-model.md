# Data Model: Generic Sheets Database Library

**Feature**: 003-generic-sheets-db
**Date**: 2026-02-18

## Library Entities (Generic — src/lib/sheets-db/)

### SheetSchema\<T\>

The core configuration object consumers provide to define how an entity type maps to a Google Sheet.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| sheetName | string | Yes | Tab name in the spreadsheet (e.g., "Contacts") |
| headers | string[] | Yes | Column header labels, in order |
| readRange | string | Yes | A1 range for reading data rows (e.g., "Contacts!A1:D") |
| writeRange | string | Yes | A1 range for writing headers + data (e.g., "Contacts!A1:D") |
| clearRange | string | Yes | A1 range to clear before writes (e.g., "Contacts!A1:D10000") |
| parseRow | (row: unknown[], index: number) => T \| null | Yes | Converts a sheet row to a typed entity, or null to skip |
| toRow | (entity: T) => unknown[] | Yes | Converts a typed entity to a sheet row |
| validate | (entity: T) => void | No | Throws SheetsDbError on invalid entity. Opt-in. |
| appendSupported | boolean | No | Whether append operations are allowed (default: false) |
| formatting | FormattingRule[] | No | Column formatting rules for this sheet |

**Validation rules**:
- `sheetName` must be non-empty
- `headers` must have at least 1 element
- `readRange`, `writeRange`, `clearRange` must be non-empty strings
- `parseRow` and `toRow` must be functions
- No two schemas may share the same `sheetName`

---

### FormattingRule

Declares formatting for a column range within a sheet.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| startCol | number | Yes | Start column index (0-based) |
| endCol | number | Yes | End column index (exclusive) |
| startRow | number | No | Start row index (default: 1 to skip headers) |
| endRow | number | No | End row index (default: 10000) |
| bold | boolean | No | Apply bold text |
| fontSize | number | No | Font size |
| horizontalAlignment | string | No | "LEFT", "CENTER", "RIGHT" |
| numberFormat | { type: string; pattern?: string } | No | Number format (CURRENCY, PERCENT, etc.) |

---

### SheetsClientConfig\<S\>

Configuration passed to the client factory.

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| token | string | Yes | Google OAuth access token |
| spreadsheetId | string | Yes | Google Sheets spreadsheet ID |
| schemas | S (Record\<string, SheetSchema\<any\>\>) | Yes | Map of schema key to schema definition |

---

### Repository\<T\>

The bound CRUD interface returned per schema. Generated by the library, not defined by consumers.

| Method | Signature | Description |
|--------|-----------|-------------|
| readAll | () => Promise\<T[]\> | Read all rows, parse via schema.parseRow |
| writeAll | (records: T[]) => Promise\<void\> | Validate + clear + write headers + data |
| append | (records: T[]) => Promise\<void\> | Validate + append rows (throws if !appendSupported) |

---

### SheetsDbClient\<S\>

The main client object returned by the factory.

| Member | Type | Description |
|--------|------|-------------|
| repo | (key: keyof S) => Repository\<InferEntity\<S[key]\>\> | Get typed repository by schema key |
| batchSync | (payload: { [K in keyof S]?: InferEntity\<S[K]\>[] }) => Promise\<void\> | Clear all + write all in two API calls |
| ensureSchema | () => Promise\<void\> | Create missing sheets |
| applyFormatting | () => Promise\<void\> | Apply all registered formatting rules |
| extractSpreadsheetId | (urlOrId: string) => string \| null | URL parsing utility |

---

### TransportContext (Internal)

Internal connection state. Not exposed to consumers.

| Field | Type | Description |
|-------|------|-------------|
| token | string | OAuth access token |
| spreadsheetId | string | Spreadsheet ID |

---

### SheetsDbError (Unchanged)

| Field | Type | Description |
|-------|------|-------------|
| message | string | Human-readable error message |
| kind | SheetsDbErrorKind | Discriminant: AUTH_ERROR, RATE_LIMIT, NETWORK_ERROR, VALIDATION_ERROR, SCHEMA_ERROR, API_ERROR |
| issues | ValidationIssue[] | Field-level issues (for VALIDATION_ERROR) |

## Domain Entities (Ortho-specific — src/lib/ortho-sheets/)

These types are **moved out** of sheets-db and into the Ortho domain layer. They are unchanged from the current implementation.

### Expense, Income, Debt, DebtPayment, OwnerTransfer, PresetTransaction

All existing entity types from `src/lib/sheets-db/types.ts` move to `src/lib/ortho-sheets/types.ts`. No field changes.

### MonthTotals

Write-only aggregation type for the Totals sheet. Moves to `src/lib/ortho-sheets/types.ts`.

### SyncPayload (Ortho-specific)

The Ortho-specific batch sync payload. Moves to `src/lib/ortho-sheets/types.ts`. The generic library uses `Record<string, any[]>` instead.

### SheetIds (Ortho-specific)

Mapping of Ortho sheet names to numeric IDs. Moves to `src/lib/ortho-sheets/types.ts`.

## Entity Relationships

```
Consumer (Ortho) defines:
  SheetSchema<Expense>  ──registers──▶  SheetsDbClient
  SheetSchema<Income>   ──registers──▶  SheetsDbClient
  SheetSchema<Debt>     ──registers──▶  SheetsDbClient
  ...

Library provides:
  SheetsDbClient ──creates──▶ Repository<Expense>
  SheetsDbClient ──creates──▶ Repository<Income>
  SheetsDbClient ──creates──▶ Repository<Debt>
  ...

  SheetsDbClient ──uses──▶ TransportContext ──calls──▶ Google Sheets API
```
